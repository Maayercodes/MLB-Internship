# Python Data Analysis – Data Cleaning & Visualization

## About This Project

This repository contains my Python data analysis practice and mini project. Throughout this learning task, I explored how to clean raw datasets, perform basic data analysis, and create visualizations using Python.

The work covers three main areas:

1. **Data Cleaning:** Learning how to prepare raw data for analysis.
2. **Data Visualization:** Learning how to represent data through different charts and graphs.
3. **Mini Project – Student Performance Dashboard:** Applying the concepts I learned to analyze student performance and discover meaningful insights.

## 1. Data Cleaning

Learned and practiced data cleaning techniques using Pandas and NumPy.

**Tasks Performed:**
- Loaded and explored a CSV dataset.
- Identified missing values.
- Handled missing values using mean imputation.
- Identified and removed duplicate records.
- Renamed columns for better readability.
- Created a new column to calculate students' average scores.
- Categorized students based on their performance.
- Exported the cleaned dataset into a new CSV file.

## 2. Data Visualization

Learned how to visualize data using Matplotlib and Seaborn.

**Charts Created:**
- **Bar Chart:** Compared students' average scores.
- **Histogram:** Analyzed the distribution of average scores.
- **Scatter Plot:** Explored the relationship between Math and Reading scores.
- **Pie Chart:** Visualized students' performance categories.
- **Box Plot:** Compared score distributions across different subjects.

## 3. Mini Project – Student Performance Dashboard

Applied data cleaning, analysis, and visualization techniques to build a Student Performance Dashboard.

**Project Objectives:**
- Calculate the total number of students.
- Find average marks in Math, Reading, and Writing.
- Identify the Top 5 performing students.
- Find students who need improvement.
- Identify the subject with the highest class average.
- Visualize the analysis using appropriate charts.

**Project Outputs:**
- Cleaned student performance dataset.
- Student performance analysis.
- Top 5 performing students.
- Subject average comparison.
- Student performance distribution charts.
- PNG images of the generated visualizations.

## Key Learning Outcomes

Through this practice, I learned:
