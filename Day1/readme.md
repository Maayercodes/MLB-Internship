## Mini Projects

### 1. Student Grading System

A console-based application that takes student information and marks, calculates average marks and assigns grades.

### 2. Student Record Management System

A menu-driven application that allows users to:

- Add students
- View students
- Search students
- Update student information
- Delete students

## Challenges Faced
Managing multiple student records using lists and dictionaries.

Implementing search, update, and delete operations without built-in methods.

## Solutions Implemented
Used dictionaries to store student information and lists to manage multiple records.
Used loops and conditional statements to implement CRUD operations and input validation.

## Learning Outcomes
Learned how to combine lists and dictionaries in a real-world project.
Improved understanding of loops, conditions, searching, updating, deleting, and menu-driven programming.
